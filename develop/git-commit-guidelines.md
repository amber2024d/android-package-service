# Git 提交规范

提交信息使用中文，保持短句、具体、可追溯。

## 格式

```text
类型：一句话说明做了什么
```

可选类型：

```text
文档
功能
修复
重构
测试
构建
配置
清理
```

## 示例

```text
文档：补充 Provider 优先级说明
功能：实现 fake provider 查询接口
修复：校验 XAPK manifest 版本字段
配置：新增 Docker Compose NAS 挂载示例
```

## 规则

- 首行不超过 50 个中文字符。
- 用祈使式或结果式短句，不写“更新一下”“修改若干内容”。
- 一次提交只表达一个主题；混合改动先拆开。
- 提交正文可选，需要时说明原因、影响和验证方式。
- 不在提交信息里写密钥、token、内部账号或上游短期下载 URL。

## 正文示例

```text
修复：下载失败时继续尝试备用 URL

原因：Aptoide file.path_alt 可作为同一文件备用地址。
验证：pytest tests/download
```
